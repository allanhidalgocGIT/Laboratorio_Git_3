Mi proyecto de aprendizaje con Git y GitHub

Allan David Hidalgo Cerdas

Git es un sistema de control de versiones que permite registrar y administrar los cambios realizados en un proyecto.

Ventajas de utilizar Git

  • Permite guardar diferentes versiones de un proyecto.
  • Facilita el trabajo en equipo.
  • Permite recuperar versiones anteriores.

¿Qué es GitHub?

GitHub es una plataforma en línea que permite alojar repositorios Git, compartir código y colaborar con otras personas en proyectos de software.

Comandos básicos de Git

  • git init: inicializa un repositorio local.
  • git add .: agrega los cambios al área de preparación.
  • git commit -m "mensaje": guarda los cambios en el historial.
  • git push: publica los commits en el repositorio remoto.
